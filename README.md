## 👥 Role-Based Workspaces (RBAC)

* **🎓 Student Portal:** Personalized transcript, semester trajectory, weak-topic AI remediation with video/notes, career roadmap, T&P practice assessments, 1-click drive applications, and resume ATS auditing.
* **👨‍🏫 Faculty Portal:** Lecture attendance marking, continuous internal evaluation gradebook entry, class weak-topic diagnostics, and high-risk student counseling.
* **👔 T&P Officer (TPO) Portal (Prof. P. J. Patil):** Corporate drive creation (Google, Microsoft, TCS, Deloitte, Tata Motors, Palo Alto, Accenture), automated candidate eligibility shortlisting, interview round tracking, and package statistics.
* **🏛️ Principal & Admin Portal (Dr. K. I. Patil):** Executive campus scorecard, 7 disciplines & course curricula, autonomous profile, RBAC matrix, and NAAC/NBA accreditation data export.
* **📞 Institutional Helpdesk & Contact Us:** Central ticketing system with automated reference IDs and real-time administrative logs.
